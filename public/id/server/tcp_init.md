# Swoole\Server

Bagian ini mencakup semua method, properti, item konfigurasi, dan event dari kelas `Swoole\Server`. Kelas `Swoole\Server` adalah kelas dasar untuk semua server gaya asynchronous, dengan `Swoole\Http\Server`, `Swoole\WebSocket\Server`, dan `Swoole\Redis\Server` di bab-bab selanjutnya sebagai subclass-nya.
