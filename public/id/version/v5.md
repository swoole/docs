Mode Runtime Baru (`swoole-cli`)
----
`5.0` akan menambahkan dukungan `swoole-cli`, `swoole` akan disediakan sebagai program mandiri seperti `node.js`, bukan sebagai ekstensi `PHP`.
Selain itu `swoole-cli` akan memangkas `php-src` sebanyak mungkin, menghapus mekanisme, modul, ekstensi, fungsi, tipe, konstanta, kode yang tidak berguna, sehingga seluruh program dapat dikompilasi dalam hitungan menit.

```shell
htf@htf-ThinkPad-T470p:~/workspace$ ./swoole-cli -v
Swoole 5.0.0 (cli) (built: Nov 26 2021 07:22:46) 
```

### Kompilasi Statis Tanpa Dependensi
`swoole-cli` akan menggunakan kompilasi statis sepenuhnya, `libc` dan `libstdc++` menggunakan `musl`, dan akan menyertakan library dan ekstensi `openssl` dan `curl`. Pengguna dapat memodifikasi skrip build untuk menambahkan lebih banyak ekstensi pihak ketiga.
Sehingga program `swoole` tidak lagi bergantung pada `.so` sistem apa pun, dapat disalin dan didistribusikan di sistem `linux` mana pun.

```shell
htf@htf-ThinkPad-T470p:~/workspace$ ldd swoole-cli
Bukan file eksekusi dinamis
htf@htf-ThinkPad-T470p:~/workspace$ 
```

### Menghapus Mekanisme Pemuatan Ekstensi Dinamis
Menghapus fungsi `dl()` dan mekanisme pemuatan ekstensi dinamis konfigurasi `extension={name}.so` di `php.ini`, semua ekstensi harus dikompilasi statis.
`swoole-cli` mengizinkan sistem build kustom untuk menambahkan ekstensi ke daftar modul.

Upload File Besar
----
Mulai `5.0` server `HTTP` menambahkan dukungan untuk upload file besar, dengan mengatur parameter `upload_max_filesize` untuk mengontrol ukuran maksimum file yang diizinkan untuk diupload.
Berbeda dengan `package_max_length`, fitur upload file besar menulis konten file dari `form-data` langsung ke file sementara, keuntungannya adalah tidak memakan terlalu banyak memori, sehingga dapat menyelesaikan upload file besar.
`package_max_length` dapat diatur ke `2M`, `upload_max_filesize` diatur ke `2G`, setiap koneksi hanya membutuhkan memori `2M` untuk menyelesaikan upload file `2G`.

```php
$server->set([
    'upload_max_filesize' => 2 * 1024 * 1024 * 1024, // 2G
    'package_max_length' => 2 * 1024 * 1024, // 2M
]);
```

Daftar Detail
----
### Penambahan
- Menambahkan item konfigurasi `Server`: `max_concurrency`, dapat membatasi jumlah maksimum permintaan konkuren untuk layanan `HTTP1/2`, mengembalikan error `503` jika terlampaui
- Menambahkan item konfigurasi `Coroutine\Http\Client`: `max_retries`, saat terjadi kegagalan koneksi atau `HTTP 502/503`, secara otomatis mengganti node untuk percobaan ulang
- Menambahkan item konfigurasi global `name_resolver`, memperkuat kemampuan resolusi nama domain, sebelum `5.0` nama domain hanya bisa menggunakan resolusi `DNS`, setelah `5.0` dapat dikonfigurasi `name_resolver` untuk mengubah resolusi nama menggunakan plugin penemuan layanan seperti `Consul` atau `Nacos`
- Menambahkan `Coroutine::getExecuteTime()`, dapat memperoleh waktu eksekusi aktual coroutine (tidak termasuk waktu dalam status `yield`)
- Menambahkan konfigurasi `upload_max_filesize`, mengizinkan upload file besar

### Penguatan
- Tipe kuat, semua parameter dan nilai kembali fungsi serta metode kelas menambahkan batasan tipe
- Semua metode konstruktor yang gagal diubah menjadi melempar exception

### Penghapusan
- Menghapus nama kelas bergaya `PSR-0`, seperti `swoole_http_server` harus diubah menjadi `Swoole\Http\Server`
- Menghapus penambahan otomatis `Event::wait()` di `shutdown function`, harus memanggil `Event::wait()` secara eksplisit untuk memasuki event wait, atau menggunakan container seperti `Co\run()`, `Server::start()`, `Process::start()`, `Process\Pool::start()`, dll.
- Menghapus alias `Server::tick/after/clearTimer/defer`, gunakan langsung `Timer::tick()/Timer::after()/Timer::clear()/Event::defer()`
