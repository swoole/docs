# v6.0
- Menambahkan dukungan mode multi-thread
- Menghapus klien `Coroutine\Redis`, `Coroutine\MySQL`, `Coroutine\PostgreSQL`, telah digantikan oleh `ext-redis`, `mysqli`, `pdo_mysql`, `pdo_pgsql`

Mulai versi `6.0`, thread secara bertahap akan menggantikan proses sebagai container runtime default, membawa perubahan baru:

## Struktur Data Konkuren yang Lebih Baik

Di versi sebelumnya, diperlukan `Redis` atau `Table` atau komunikasi pipa `IPC` untuk berbagi data antar proses,
di versi baru internal menyediakan tiga struktur data konkuren yang aman untuk thread: `Map`, `ArrayList`, `Queue`. Selain itu `Atomic` dan `Lock` juga telah diadaptasi untuk mode multi-thread.

### Concurrent Map
Container asosiatif `Key-Value`, kompleksitas waktu membaca data berdasarkan `Key` adalah `O(1)`

```php
$args = Thread::getArguments();

if (empty($args)) {
    $map = new Swoole\Thread\Map;
    $thread = new Thread(__FILE__, $map);
    // Tulis di thread induk
    $map['uuid'] = uniqid();
    $thread->join();
} else {
    $map = $args[0];
    sleep(1);
    // Baca di thread anak
    var_dump($map['uuid']);
}
```

### Concurrent ArrayList
Container berurutan, dapat menambahkan elemen, kompleksitas waktu membaca data berdasarkan indeks adalah `O(1)`

```php
$args = Thread::getArguments();

if (empty($args)) {
    $list = new Swoole\Thread\ArrayList;
    $thread = new Thread(__FILE__, $list);
    // Tulis di thread induk
    $list[] = uniqid();
    $list[] = uniqid();
    $thread->join();
} else {
    $list = $args[0];
    sleep(1);
    // Baca di thread anak
    var_dump($list[0]);
    var_dump($list[1]);
}
```

### Concurrent Queue
Struktur data first-in-first-out, dapat push dan pop data.
- `push($data)` memasukkan ke antrian, parameter kedua dapat mengontrol `push()` untuk membangunkan thread lain yang sedang menunggu `pop()`
- `pop()` mengeluarkan elemen, parameter kedua dapat menentukan waktu tunggu, jika antrian kosong dapat tertidur, menunggu operasi `push()` untuk membangunkan

```php
use Swoole\Thread;
use Swoole\Thread\Queue;

$args = Thread::getArguments();
$c = 4;
$n = 128;

if (empty($args)) {
    $threads = [];
    $queue = new Queue;
    for ($i = 0; $i < $c; $i++) {
        $threads[] = new Thread(__FILE__, $i, $queue);
    }
    while ($n--) {
        $queue->push(base64_encode(random_bytes(16)), Queue::NOTIFY_ONE);
        usleep(random_int(10000, 100000));
    }
    $n = 4;
    while ($n--) {
        $queue->push('', Queue::NOTIFY_ONE);
    }
    for ($i = 0; $i < $c; $i++) {
        $threads[$i]->join();
    }
    var_dump($queue->count());
} else {
    $queue = $args[1];
    while (1) {
        $job = $queue->pop(-1);
        if (!$job) {
            break;
        }
        var_dump($job);
    }
}
```

### Lock
```php
$args = Thread::getArguments();

if (empty($args)) {
    $lock = new Swoole\Lock;
    $lock->lock();
    $thread = new Thread(__FILE__, $lock);
    $lock->lock();
    echo "main thread\n";
    $thread->join();
} else {
    $lock = $args[0];
    sleep(1);
    $lock->unlock();
}
```

### Atomic Counter
```php
$args = Thread::getArguments();
$c = 4;
$n = 128;

if (empty($args)) {
    $threads = [];
    $a1 = new Swoole\Atomic;
    $a2 = new Swoole\Atomic\Long;
    for ($i = 0; $i < $c; $i++) {
        $threads[] = new Thread(__FILE__, $i, $a1, $a2);
    }
    for ($i = 0; $i < $c; $i++) {
        $threads[$i]->join();
    }
    var_dump($a1->get(), $a2->get());
} else {
    $a1 = $args[1];
    $a2 = $args[2];

    $a1->add(3);
    $a2->add(7);
}
```

## Alat Debug yang Lebih Nyaman
Semua worker thread berada dalam satu proses, alat seperti `gdb`, `strace` dapat langsung melacak semua thread.
